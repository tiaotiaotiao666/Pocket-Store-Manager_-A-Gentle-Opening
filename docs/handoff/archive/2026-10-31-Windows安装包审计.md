# 历史摘要：Windows 安装包审计

> 日期：2026-10-31
> 状态：历史。当前打包要求以 `docs/windows-deployment.md` 和 `docs/待完成目标.md` 为准。

## 当时结论

前端 Vite 构建和自动化测试通过，但 Windows NSIS 安装包未生成。阻塞为 electron-builder 下载 Electron 运行时 ZIP 时连接 GitHub Releases 超时，错误为 `ERR_ELECTRON_BUILDER_CANNOT_EXECUTE`，没有证据表明是 React 源码或 Vite 编译导致。

当时 lockfile 的 Electron 为 33.4.11，旧构建记录中的 33.2.1 是版本漂移；`node_modules/electron` 存在不等于 electron-builder 的发行 ZIP 已缓存。

## 当时记录的其他边界

- 部署动画不会导出或发布，小程序导出 IPC 虽存在但未被会话式 UI 调用。
- electron-builder 提示缺少 author，属于元数据警告，不是下载失败根因。
- 开发模式和 `electron --version` 成功不能代替安装包验收。

## 后续必须执行

1. 使用团队可访问的 Electron 下载源或预热受信任缓存，不关闭校验、不提交运行时二进制。
2. 在干净 Windows x64 环境重新构建，确认 NSIS 和 win-unpacked 真实产物。
3. 安装并验证主窗口、资源加载、文件选择、中文路径、导出和卸载。
4. 核对 electron-builder files：当前导出脚本运行时引用 `src/domain/catalog.mjs`，而 files 列表未包含 `src/`，安装包导出需要重点验证和修复。
5. 补齐桌面 IPC/安装包契约测试与发布元数据。

本文不表示上述事项已经完成。
