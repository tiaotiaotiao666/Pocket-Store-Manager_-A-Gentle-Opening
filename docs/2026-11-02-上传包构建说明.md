## 3. 真实执行命令与结果

### 3.1 桌面端安装包构建

第一次直接执行 `npm run build:win` 失败：

- `electron-builder` 需要下载 Electron `33.4.11`，GitHub 连接超时。

第二次改用国内镜像：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npm run build:win
```

镜像下载成功，但解压 `winCodeSign-2.6.0.7z` 时报：

```text
ERROR: Cannot create symbolic link : 客户端没有所需的特权
```

原因：该压缩包内含 macOS 的 `darwin/10.12/lib/libcrypto.dylib`、`libssl.dylib` 符号链接，本机无管理员权限。

解决方式：手动用项目自带 `7za.exe` 以 `-snl-` 禁用符号链接恢复，并排除 `darwin` 目录，解压到 electron-builder 期望的缓存目录：

```powershell
$CACHE = "$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign"
& "node_modules\7zip-bin\win\x64\7za.exe" x -bd -y -snl- `
  "$CACHE\354770479.7z" "-o$CACHE\winCodeSign-2.6.0" "-xr!darwin"
```

再次执行 `npm run build:win` 成功，真实输出：

```text
• packaging       platform=win32 arch=x64 electron=33.4.11 appOutDir=release\win-unpacked
• building        target=nsis file=release\智能开店 Setup 0.2.0.exe archs=x64
• building block map  blockMapFile=release\智能开店 Setup 0.2.0.exe.blockmap
```

安装包未签名，日志为 `no signing info identified, signing is skipped`。这是预期结果，不影响本地安装演示，但 Windows SmartScreen 会提示未知发布者。

### 3.2 上传包生成

```powershell
node scripts/build-upload-package.cjs
```

首次执行得到 361.65 MB，原因：排除列表漏了 `.tools/`，把本机 MySQL 安装包（280 MB）与数据库文件打进去了。已在脚本中补上 `.tools`、`.npm-logs`、`.npm-cache`、`.npm-cache-run`，并增加任意层级的 `.tools` 排除。

另外发现根目录出现一份 5 MB 的 `docs.rar`，内容与 `source/docs/` 重复，已在打包时排除（原文件未删除）。本构建说明文档本身也排除出上传包，避免包内文档记录的数据与包体自相矛盾。

## 6. 复现方式

