# 「预览新模块」小程序真实预览 — 开发说明

日期：2026-11-06

## 1. 目标

在「选择小程序模板」页面，用户选好模板、写下修改意见并提交后，点手机预览下方的「预览新模块」，应能：

1. 把当前模板 + 已提交的修改意见（presentation patch）写进真实小程序工程；
2. 自动用微信开发者工具打开该工程；
3. 在开发者工具里看到「需求最终页面」的真实 WXML 渲染（不是 React 复刻）。

实时渲染不是必要条件；重点是最终预览正确。

## 2. 链路

```text
模板页「预览新模块」
  → buildPlanFromSession(state)          汇总当前模板 + presentation patch
  → exportProject({ parentDir: '__preview__' })
  → 固定目录：%APPDATA%\smart-store-generator\preview-projects\<店铺名>-预览-<时间戳>
  → 修正 project.config.json 的 appid（touristappid → 有效 appid）
  → Electron IPC preview:open-devtools
  → cli.bat open --project <预览目录>
  → 微信开发者工具打开真实工程
```

## 4. 前置条件

1. 安装 **Node.js 20+**。
2. 安装 **微信开发者工具**，并：
   - 扫码登录；
   - 设置 → 安全设置 → 开启 **服务端口**；
   - 设置 → 代理设置 → **不使用代理**；
   - 详情 → 本地设置 → 勾选 **不校验合法域名、web-view、TLS、HTTPS 证书**。
3. 项目内准备本机 MySQL（见第 5 节）。
4. 桌面端运行：`npm run desktop:dev`（自带 Vite 5173，不要另外再开 `npm run dev`）。

## 5. 组员一键初始化环境

在**管理员 PowerShell**执行：

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File scripts\local-env\setup-windows-env.ps1
```

脚本会依次完成：

```text
检查管理员 / Node 20+
检查 3306 是否被其他程序占用
下载 MySQL 8.0.28（阿里云镜像，约 212 MB）
解压到 .tools\mysql-8.0.28-winx64
初始化数据目录 .tools\mysql-data
注册并启动 Windows 服务 SmartStoreMySQL
创建 smart_store / smart_store_test 与账号 smart_store/smart_store_dev
生成 server/.env（DATABASE_URL、TEST_DATABASE_URL、CACHE_DRIVER=memory）
安装根目录与 server 依赖
prisma generate → prisma migrate deploy → npm run db:seed
```

完成后启动后端：

```powershell
npm run server:dev
```

验证：

```powershell
curl.exe http://127.0.0.1:3000/api/v1/readyz
```

应返回 `{"status":"ok","database":"ok","cache":"memory",...}`。

说明：

- MySQL 是**项目内便携版**（`.tools/`，已被 `.gitignore` 忽略），不会全局安装，也不会随源码分发。
- 组员 clone 后 `.tools/` 不存在，必须执行一次上面的脚本；否则后端会报 `P1001 Can't reach database server at 127.0.0.1:3306`。
- Windows 未安装 Redis，缓存使用 `memory`；不影响页面/订单数据。

## 6. 修改意见如何进入预览

- 模板页「对话修改」当前走**本地 Mock 规则**（未接真实模型时）。
- 必须点 **「应用修改」** 提交；未提交的输入框文字不会进入预览。
- 提交后生成 `presentation patch`（主题 / 尺寸 / 槽位 / 文案），点预览时随 `buildPlanFromSession(state)` 写进工程。
- 本地 Mock 配色关键词：橙/暖、绿/森、蓝/海、紫、红/喜庆、金/高级、深色/夜间、**黑白/灰度/去色/无彩色**。
- 切换模板会清空当前模板的 patch（`SELECT_TEMPLATE` 的既有设计），主题回到新模板默认色。

## 7. 常见问题

### 7.1 点了按钮但微信开发者工具没打开

按顺序核对：

1. 预览目录里是否生成了新工程：`%APPDATA%\smart-store-generator\preview-projects`
2. 直接执行：
   ```powershell
   & "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" open --project "<预览工程目录>"
   ```
3. 如果报 `不存在此 AppID ... (code 10)`，检查该工程 `project.config.json` 的 `appid` 是否为 `touristappid`。

当前代码会在打开前自动把 `touristappid` 替换为 `miniprogram/project.config.json` 的有效 appid。

### 7.2 提示“登录用户不是该小程序的开发者”

这是 appid `wx3b1c04f63cf6cfd0` 的成员权限问题，与华为账号、手机号无关。只影响点在工具里生成“预览二维码”，不影响模拟器加载页面。可让管理员在微信公众平台把当前微信加为开发者/体验成员。

### 7.3 改了意见，预览还是旧主题

- 确认点过「应用修改」，变更列表里有对应条目；
- 当前按钮每次都会按最新 patch 重新导出（不再复用旧工程）；
- 检查微信工具打开的是不是最新时间戳的目录。

### 7.4 主题“黑白不彻底”

Mock 黑白主题覆盖 7 个 token（pageBackground / primaryColor / accentColor / textColor / tabBarBackground / tabBarColor / tabBarSelectedColor），模板里部分固定暖色（渐变、装饰块）不在 token 内，会残留少量暖色。需要彻底黑白则要扩展模板样式 token 化。

### 7.5 预览目录越积越多

固定目录不会自动清理，可手动删除：

```text
%APPDATA%\smart-store-generator\preview-projects
```

## 8. 能力边界

- 浏览器（5173）里点按钮无法调起本地微信开发者工具，只提示“需在桌面端使用”。
- 微信开发者工具是 Windows 原生窗口，无法嵌入 agent 页面；MCP 也不能嵌入。
- 桌面端与后端独立：后端不可达时，真实数据/生图仍会失败。
- 组员要“打开就能用”，仍需各自执行一次环境脚本，或采用后端上云方案（客户端指向云端 API）。
