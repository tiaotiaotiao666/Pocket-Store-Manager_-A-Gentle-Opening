## 1. 第三方生图服务事实（先验证后接入）

- 端点：`POST https://imagelfk.cc.cd/v1/images/generations`（服务方只在 `.env` 里配置，代码里不硬编码）
- 模型名：`gpt-image-2.6`（`GET /v1/models` 里实际存在 `gpt-image-2`、`gpt-image-2.5`、`gpt-image-2.6`；本次使用 `gpt-image-2.6`）
- 请求字段（实测可用）：`{"model":"gpt-image-2.6","size":"1024x1024","n":1,"response_format":"b64_json","quality":"low"}`
- 响应形态：**同步**，HTTP 200，字段 `url | revised_prompt | size | b64_json`，另有 `usage {input_tokens, output_tokens}`
- 尺寸：请求 `1024x1024` 实际返回 `1254x1254`；请求 `1536x1024` 返回 `1536x1024`
- 鉴权：必须带 `Authorization: Bearer <key>`；不带 → `401 invalid_api_key`（证明匿名调用不会消耗 Key）
- 错误形态：错误模型名 → Cloudflare HTML 502；401 → `invalid_api_key`；限流 → 429
