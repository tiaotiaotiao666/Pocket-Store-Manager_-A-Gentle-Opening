# R3 中文录屏脚本（约 7 分 30 秒）

主演示只走普通开店主线。截图重构支线不打开、不作为启动或导出前提。录屏分辨率建议 1920×1080，桌面窗口至少 1120×740；隐藏通知、文件内容和环境配置，画面不得出现密钥、Token 或鉴权信息。

## 录屏前准备（不在成片计时内）

- 按 `docs/R3-最终交付冻结.md` 启动后端与桌面端，readyz 为 200 且 `database=ok`，模型通道为「本机服务」。
- 云栖小馆 seed 已完成，桌台 A1/A2/B1/B2 可选；微信开发者工具已登录。
- 准备一个**新命名的普通项目**用于现场录入；同时保留已验收的「云栖小馆」及 R1 正式导出作为明确标注的故障备用，不覆盖旧工程。
- 清空无关购物车/旧窗口，确认导出父目录可写且没有同名目录。
- 完整预演一次，但不在 R3 重新执行自动化验收，不打开截图重构。

## 不可剪接冒充的画面

1. **真实 AI 生图**：可以剪掉无变化的等待时长，但必须保留同一次操作的发起、返回与选用关系；失败回包后不能接旧图称“本次生成”。
2. **模板修改/撤销**：before/after 与撤销结果须属于同一项目同一轮；不能用表单手改或刷新后的状态冒充 Agent/撤销。
3. **正式导出**：进度成功、结果目录和海报入包须对应同一份工程；旧导出必须明确标为 R1 备用证据。
4. **React / 正式导出 / 微信 / 真机**：四类画面不可互换。React 预览不能冒充微信；微信工具不能冒充真机。
5. **真实订单与演示支付**：选桌、加购、结算、订单号及 `UNPAID → DEMO_PAID` 建议一镜到底；不得把不同订单号剪成一笔交易。
6. **D2 预览海报**：必须是重新发起的预览副本，不能用正式导出目录代替。
7. **支线状态**：不得插入历史 T6 PASS 暗示当前截图重构可用；若提及，只能说当前 BLOCKED。
