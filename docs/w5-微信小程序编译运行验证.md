## 5. 运行期依赖的本机服务

导出的 `config/env.js` 默认指向 `http://127.0.0.1:3000/api/v1`、门店 `store-demo-001`。
本机 NestJS 服务端当前**无法启动**：`server/src/agent/agent.service.ts:188/264` 有两个既有
TypeScript 错误（`ValidatedAgentImage` 与 `AgentProviderImage` 类型不匹配），`nest start --watch`
报 `Found 2 errors`（日志 `.arts/w5/server2.log`）。该问题与本轮微信小程序改动无关，未在 W5 内修改。

为了让小程序走真实渲染路径，本轮新增只读桩后端：

```
node scripts/wechat-runtime-stub.cjs --port 3000   # 演示数据，非真实服务
```

桩后端只提供 `stores/:id`、`stores/:id/catalog`、`tables`、`posters`、演示登录 5 个接口，
不接数据库、不联网，页面上看到的菜品/门店均为桩数据，**不构成真实后端验收**。
