1. **插槽三段式锚点**：`home-hero`、`home-marketing`（home）、`menu-aside`（menu）。每段锚点恰好出现一次，fallback 保留改造前真实标签（首页为 `<store-header>`）。
2. **主题 Token 化**：`app.wxss` 顶部 `@import "theme.generated.wxss";`，删除全部 `--store-*` 硬编码定义；颜色统一走 `--store-*`，并保留 `--color-*` 别名兼容既有组件。
3. **公开配置 v2 最小示例**：`config/store.generated.js` 含 `schemaVersion: 2`、`meta`（12 项）、`store/api/catalog/fulfillmentOptions/theme/capabilities/demoPaymentDisclaimer`，无 `priceText/template/icons`。

5. **页面扩展占位**：7 个页面各有 `extensions.generated.js`（默认 `module.exports = {}`），home/menu 通过 `config/slots.generated.js` 注入 `slotProps`。
