## 4. 设计要点

- preview 不写库、不消耗幂等键；`previewToken = <expiresAtMs>.<sha256(storeId+userId+payload+expiresAtMs)>`。
- apply 单事务：分类/商品/桌号 → 门店 profile → `configVersion+1`、`catalogVersion+1` → `store_imports(APPLIED, resultJson)`。
- 冲突默认 `skip/conflict`，不静默改价、不静默上架、不删除未声明项。
- 缓存失效在事务外；失败返回 `cacheRefreshed:false`，不回滚数据。
- `STAFF`、跨店、顾客一律 `403 FORBIDDEN`。
- 公开 `GET /stores/:id/tables` 只返回 `id/name/sortOrder`，排序稳定。
