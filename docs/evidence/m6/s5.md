## 2. 配置 v2 口径

- `meta` 固定 12 项：`configSchemaVersion/storeConfigVersion/catalogVersion/apiContractVersion/recipeId/recipeVersion/lockDigest/generatedAt/generatorVersion/planDigest/mode/versionGaps`。
- `generatedAt` 固定 `1970-01-01T00:00:00Z`（确定性产物；真实时间只在报告）。
- production：`api.baseUrl` 必须 HTTPS；`storeConfigVersion/catalogVersion` 任一为 `null` → `VERSION_GAP_REQUIRED` 拒绝。
- 旧 `schemaVersion: 1` → `STORE_CONFIG_SCHEMA_UNSUPPORTED`。
- `capabilities.onlineReady` 与 `previewOnly` 交集 → `CAPABILITY_INTERSECTION`。
- 金额唯一事实为 `priceCents`，禁止 `priceText/totalCents`。

## 3. 版本守卫

- `compareVersions(local, online)`：本地 < 在线 → 提示“菜单配置已更新，请下拉刷新后再点餐”；相等/本地更高 → 不提示；任一缺失 → `unknown`，不做错误判断。
- `resolveTables(remote, demoFallback)`：在线有桌号用在线；不可用回落演示桌号并标注。
