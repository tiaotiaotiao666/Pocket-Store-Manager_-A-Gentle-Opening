## 3. 关键断言

- 六份 Schema 均带 `status: "frozen"`、人类可读 `rules[]`，可被 JSON 解析。
- 7 份合法样例全部通过；14 份非法样例逐条返回指定 `code` 与 JSON `path`（不是只断言“抛错”）。
- 版本只接受精确 `MAJOR.MINOR.PATCH`：`latest` → `VERSION_NOT_EXACT`。
- Plan 禁止字段（`source/code/script/command/url/token/...`）返回 `PLAN_FIELD_FORBIDDEN`，路径精确到 `features[0].source`。
- 金额唯一事实：`priceCents` 必须整数；出现 `priceText/totalCents` → `MONEY_SECOND_SOURCE`。
- 注册表摘要漂移 → `REGISTRY_DRIFT`，并输出 `{registryVersion, expectedDigest, actualDigest}`。
- 资产 `integrity` 为**目录内容摘要**（含 Manifest、源码、预览、配置），内容改动必须重新冻结。
- 组件声明与实现双向一致：多声明/少声明 prop、未触发事件 → `INTERFACE_MISMATCH`；组件顶层调用 `wx.*` → `COMPONENT_SIDE_EFFECT`。
- 安全扫描覆盖 `sk-`、私钥头、`AKIA`、连接串、内网地址、绝对路径、UNC、`file://`、外部 URL；`development` 仅放行 `127.0.0.1/localhost`。

## 4. 已知限制

- 本轮未引入第三方 Schema 校验库（按方案 A17），校验器为手写实现，新增契约字段需同步补代码与样例。
- `REGISTRY_DRIFT` 只能发现“内容变了但未重新冻结”，不能判断变更是否合理；合理性依赖评审。
