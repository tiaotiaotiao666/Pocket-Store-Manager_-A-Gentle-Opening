### 5.1 契约偏差（必须如实记录）

对照 `classic-blocks` 与 `classic-noblock`：**页面与组件源码逐字节一致**，差异仅在
`README.md`、`composition.lock.json`、`config/store.generated.js`、`generation-report.json`、
`project.config.json`、`生成报告.md`（元数据与 projectName 差异）。

原因（`scripts/composer/emit.cjs:654-701`）：组件只从 Base 复制，可选 UI Block 通过
`Plan.components` 仅参与 `resolve.cjs:129` 的引用校验，**不会覆盖 Base 同名组件实现**；
只有 Feature Pack 在 `graph.assignments` 命中插槽时才会被复制。

影响：M7「3 个 UI Block 资产」目前是**登记与校验层面的资产**，不是可替换 Base 实现的覆盖层。
若后续要求 Block 真正覆盖 Base，需在 emit 增加 `components` 覆盖复制逻辑并重新冻结资产摘要。
本轮不擅自改变已冻结的 Composer 行为，按现状记录。
