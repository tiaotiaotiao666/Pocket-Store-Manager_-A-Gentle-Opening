**为什么必须加 `env -u ELECTRON_RUN_AS_NODE`**：当前 shell 预设了 `ELECTRON_RUN_AS_NODE=1`，直接 `npm run desktop:dev` 会让 Electron 以纯 Node 运行，`main.cjs` 第 16 行 `app.getPath` 立即抛 `TypeError`。这不是代码缺陷。

**重启桌面应用的标准命令**（M1、M2 关窗后、A-UI-3 使用）：

```bash
env -u ELECTRON_RUN_AS_NODE npm run desktop:dev
```

先完整关闭窗口，再执行；不要只刷新渲染层，否则主进程/preload 改动不会重新注册。
