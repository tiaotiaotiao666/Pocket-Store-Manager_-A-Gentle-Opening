## 2. 每个资产的内容

每个 UI Block / Feature Pack 均具备：
- `manifest.json`：`identity/kind/displayName/entry/interface/boundary/compatibility/requiredPages/requiresSlots/dependencies/conflicts/preview/release` 全字段。

- `preview/{normal,empty,error,long}.json`：四类可解析预览数据。

- `src/pages/home.extend.json`：声明 `pageId/slotId/component/hooks`，不包含源码或动态加载。
