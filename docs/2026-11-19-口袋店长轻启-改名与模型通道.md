# 2026-11-19 口袋店长·轻启：改名、界面去技术化与模型通道

## 1. 本轮目标（用户原话）

1. 把小程序产品名从「智能开店」改为「口袋店长·轻启」。
2. 去掉前端页面上形似乱码的字符与临时界面（例如「DeepSeek 后端（真实模型）」「运行 run_xxx」「涉及 N 个工具步骤」这类）。
3. 设置里加「自己设置模型和 API」的通道；各家协议不同，因此只支持 DeepSeek 官方 API。

## 4. 模型与 API（只支持 DeepSeek 官方协议）

### 4.1 界面

设置页新增「模型与 API」：

- 使用方式：`直连 DeepSeek（填自己的 API Key，推荐）` / `本机服务（由本机部署的模型服务提供）`
- API 地址（默认 `https://api.deepseek.com`）、模型（`deepseek-chat` / `deepseek-reasoner`）、超时
- API Key：填写 → 保存密钥；只显示「已加密保存 · 时间」；可清除
- 测试连接：发一条最小请求验证地址/模型/Key（`max_tokens: 1`）
- 明确的边界说明：这一栏只接管「开店资料」对话；图片识别、模板修改、参考截图仍由本机模型服务处理

### 4.2 安全与边界

- Key 只存在 Electron 主进程：`safeStorage.encryptString` 加密写入 `<userData>/model-key.bin`；加密能力不可用时**拒绝保存**，绝不明文落盘。
- 渲染进程只能拿到 `{configured, updatedAt}`；`config.json`、日志、诊断快照、导出工程均不含 Key。
- 只允许 `http(s)` 的干净基址 + `/chat/completions`；请求体只接受 OpenAI 兼容的 `messages` / `tools` 形状，不透传任意 JSON。
- 主进程 IPC：`settings:model-key:status|save|clear`、`settings:model:test`、`settings:model:chat`，全部走 `isTrustedSender`。

### 4.3 直连通道怎么工作

- 资料整理（纯文字）在 `directAgentRunTransport` 里跑一个小型工具循环：
  `get_store_draft` / `update_store_draft`，草稿合并与校验由本机领域层决定，模型无权改结论。
- 返回的仍是 `agent-run.v1` 外壳，交给同一套 `validateAgentRunResponse`，过程卡/会话/持久化不需要第二套逻辑。
- 上限：6 次模型调用、12 次工具调用、60 秒；重复调用折叠为 `loop_detected`，不伪造成功。
- 带图片、模板修改、截图解析仍走本机服务；直连模式下带图请求会提前给出可执行提示，而不是含糊失败。
