## 1. 项目是什么

「智能开店」是一个面向中小餐饮门店的**微信小程序生成器 + 扫码点餐演示系统**，由三部分组成：

1. **桌面生成器**：Electron + React，通过会话式引导收集门店资料、选择模板、生成并导出微信小程序工程。
2. **微信原生小程序**：顾客扫码点餐与店主接单工作台，不允许使用 Taro / uni-app 等跨端框架。
3. **NestJS 业务后端**：MySQL 存业务数据、Redis 做商品目录缓存，API 统一使用 `/api/v1` 前缀。

本包是**草稿包**，用于平台侧建档与白名单激活，不代表已经完成华为云正式部署或应用市场上架。

## 3. 桌面端安装与运行

1. 双击 `desktop/smart-store-desktop-setup-0.2.0.exe` 安装。
2. 该安装包**未做代码签名**，Windows SmartScreen 可能提示“未知发布者”，选择“更多信息 → 仍要运行”即可。
3. 安装后从开始菜单启动「智能开店」。
4. 桌面生成器可以离线演示模板选择与工程生成；若要使用真实 DeepSeek 开店 Agent，需要先启动本地或云端后端，并在设置页选择「DeepSeek 后端（真实模型）」。

## 4. 微信小程序导入

1. 解压 `miniprogram/smart-store-miniprogram-0.2.0.zip`。
2. 微信开发者工具选择「导入项目」，目录指向解压后的 `smart-store-miniprogram` 文件夹。
3. `project.config.json` 中的 AppID 是项目作者的小程序标识（AppID 不是密钥）。如果要上传到你自己的账号，请在开发者工具里替换为你自己的 AppID。
4. 首次运行前请确认后端地址：开发模式默认指向本机 `http://127.0.0.1:3000`，可在小程序 `config/env.js` 中调整。
5. 演示支付为**模拟支付**，界面会明确标注，不接入真实微信支付。

## 5. 源码本地启动

环境要求：Node.js 22 LTS 或更高版本、npm；后端另需 MySQL 8，Redis 可选。

```powershell
npm install
npm run desktop:dev
```

仅启动浏览器原型：

```powershell
npm run dev
```

后端（标准方式，需要本机 MySQL）：

```powershell
cd server
npm install
npm run db:migrate
npm run db:seed
npm run start:dev
```

Windows 本机也提供一键脚本（会检查并拉起本地 MySQL）：

```powershell
npm run server:dev
```

真实模型密钥只能写入服务端未提交的 `.env`，**不要**放进 Electron 渲染层、小程序或 `VITE_*` 变量。包内只提供 `.env.example`。

## 6. 已实现与未实现（请按此口径描述）

已实现并有代码与自动化测试：

- 桌面端会话式引导、模板选择、Composer 确定性生成、导出预检、项目持久化、图片资产、撤销/重做。
- 微信原生小程序的顾客点餐闭环：扫码进店、菜单、购物车、结算、模拟支付、订单查看。
- 店主工作台：新订单、制作状态流转、商品售卖状态切换。
- NestJS 后端六态订单、金额按整数「分」由服务端计算、商品快照、店主身份服务端校验。
- DeepSeek 文本 Agent 真实调用链路（资料收集与结构化草稿），可通过 `AGENT_PROVIDER` 切换 provider。

未实现或未验证，草稿材料中不得写成已完成：

- **未接入华为云盘古 / ModelArts**；DeepSeek 是第三方模型，只经过统一适配层。
- **生图 Provider 未接入**，前端在未配置端点时返回本地 SVG 占位图。
- **未接入真实微信支付、退款、外送、公开店主注册**；演示支付是模拟支付。
- 云端 ECS / RDS / DCS / OBS / API Gateway 的真实生产部署与压测未完成。
- 小程序真机 HTTPS、合法域名、安全区适配未验收。
- 桌面端部分健壮性人工走查项（断网、磁盘写满、异常目录等）未逐项完成。
- 本包不构成“可直接上架”的应用；每家门店仍需自己的微信账号、主体和 AppID。

## 7. 密钥与安全

- 包内**不包含**任何真实密钥：没有 `.env`、`.env.local`，没有微信 AppSecret、数据库密码、支付密钥或模型 API Key。
- 唯一的 `.env.example` 只含空值与占位说明。
- 小程序端不存放任何密钥；店主身份由后端校验，客户端不能自行授予角色。
- 上传前可用 `MANIFEST.txt` 中的 SHA256 核对文件完整性，并确认清单里没有 `.env`、`node_modules` 或 `project.private.config.json`。
