## 2. 启动前置条件

1. Windows，Node.js ≥ 20、npm ≥ 10，依赖已安装；MySQL 5.7/8.x 可用。
2. 本机配置已经准备好数据库连接及真实模型/生图服务配置。配置只放本机环境文件或应用安全配置入口，不得写进文档、截图、日志、导出工程或 Git。
3. 桌面端「设置与自检」：后端接口为 `http://127.0.0.1:3000/api/v1`，模型通道选择「本机服务」，接口路径不重复拼 `/api/v1`。
4. 微信开发者工具已安装、已登录并开启服务端口/自动化能力；CLI 路径按本机安装位置配置。
5. 本次微信运行使用**测试号/开发演示边界**，不能上传发布。不要把 AppID 后处理或测试号运行说成发布。

## 3. 启动顺序

所有命令在仓库根目录执行。以下命令只用于后续人工启动，R3 未重跑验收。

### 3.1 一键启动（优先）

```powershell
npm run start:all -- -SkipMysql -Seed
```

- 已有 MySQL 监听 3306 时使用 `-SkipMysql`；否则去掉该参数，让脚本尝试启动本机 MySQL。
- 仅启动后端可加 `-ServerOnly`；3000 被旧后端占用且 readiness 不通过时用 `-RestartBackend`。
- 不要在共享电脑的 3306 上贸然执行 `npm stop`，它可能停止当前占用该端口的 MySQL。

### 3.2 分窗口启动（便于录屏排查）

```powershell
# 窗口 A：数据库已启动后
cd server
npx prisma migrate deploy
npm run build
node dist/main.js
```

```powershell
# 窗口 B：回到仓库根目录
node server/seed-demo-store.cjs
node server/seed-demo-tables.cjs
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run agent:app
```

普通终端也可用 `npm run desktop:dev`。若 Electron 报 `getPath` 相关错误，先清除 `ELECTRON_RUN_AS_NODE` 再启动，不要改源码。

### 3.3 微信开发者工具

1. 等正式导出成功，再在桌面端打开应用内「微信预览」，或在微信开发者工具中导入正式导出目录。
2. 检查编译无错误，首页能读到「云栖小馆」及真实桌台。
3. 依次查看底部四页：首页、菜单、订单、我的；菜品详情和结算页按交互进入。
4. 需要命令行复验时，以 `scripts/wechat-devtools-run.cjs` 为固定入口；正式导出目录见第 5 节。

## 7. 常见故障与恢复

| 现象 | 先检查 | 恢复动作 |
| --- | --- | --- |
| Electron 启动即报 `getPath` | 是否继承 `ELECTRON_RUN_AS_NODE=1` | 清除该环境变量后用 `npm run agent:app` |
| Agent「请求未被接受」/404 | 后端 dist 是否旧；接口路径是否重复 `/api/v1` | 在 `server` 重建后重启；设置接口路径为 `/agent/turn`，模型通道用本机服务 |
| readyz 不通或数据库非 ok | 3000、3306、数据库配置、迁移 | 先恢复数据库和迁移，再重启后端；不要用端口存活代替 readyz |
| 本地会话 401/过期 | 后端是否重启、短期会话是否失效 | 在设置页重新连接后重试；不匿名绕过鉴权 |
| 微信无门店/菜单或桌台为空 | `store-demo-001` 数据、后端基址、两个 seed | 重新执行幂等 seed 并刷新编译；不改前端写死数据 |
| 微信自动化端口失败 | CLI 登录态、服务端口、9421 占用 | 登录并开启服务端口，换空闲自动化端口 |
| 导出 `EPERM`/`TARGET_EXISTS` | 目录权限和同名目录 | 换可写的新父目录或采用界面建议的新名称；不覆盖旧工程 |
| AI 海报失败/超时 | 第三方服务状态，保留原素材 | 如实跳过本次生成；可用已保存的 R1 真实海报继续，不伪造“本次成功” |
| D2 旧预览无海报 | 是否打开旧 `*-预览-*` 副本 | 从已采用海报的项目重新发起应用内预览，使用新副本 |
| 截图重构出现调用上限 | 当前支线本已 BLOCKED | 立即退出该支线，回到普通主线；不提高上限、不 Mock、不改状态 |
