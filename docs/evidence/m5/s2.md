## 3. 确定性口径

- `store.generated.js` 的 `meta.generatedAt` 固定为 `1970-01-01T00:00:00Z`，真实导出时间只写报告。
- `generation-report.json`、`生成报告.md`、`composition.lock.json` 不参与 `outputDigest.tree`。
- 两次生成断言逐文件 `sha256` 相同，`lockDigest` 相同（`generatedAt` 被排除）。
- 所有 JSON 统一 2 空格 + LF；文本 LF 归一化；禁止时间戳/主机名/随机数/绝对路径进入工程。

## 4. 已知限制

- `outputDigest.tree` 在写 Lock 前计算，因此不包含 Lock 与报告自身；这是有意设计，避免自引用。
- 扩展页（Plan 中不在 Base 的页面）本轮不支持，返回 `PAGE_NOT_IN_BASE`。
- 单文件大小上限 64 KB（Plan/Manifest/Lock/配置）；`app.json` 的 tabBar 列表固定 4 个 Base tab。
