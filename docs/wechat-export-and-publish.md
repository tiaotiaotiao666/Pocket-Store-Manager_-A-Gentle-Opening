# 导出工程与微信发布指引

## 导入和预览

1. 在生成器完成资料、功能、模板和风格选择，点击“导出独立小程序”。
2. 安装并打开微信开发者工具，选择“导入项目”，项目目录选刚才导出的门店目录。
3. 原型阶段可以使用游客/测试预览（如开发者工具允许）；正式业务需由店主填写自己的 AppID。检查首页、菜单、订单和我的页面，并在不同模拟器尺寸下预览。
4. 当前导出内容只提供菜单与门店资料展示，不接线上订单、支付或店主管理后台。正式营业前需先完成独立后端和安全评估。

## 独立发布主体

每家门店应使用其自己的微信小程序账号与合法主体。店主需自行注册/认证、取得 AppID、配置服务器 HTTPS 合法域名、在开发者工具上传代码并在公众平台提交审核及发布。生成器不会将门店挂靠到生成器运营主体名下，也不会代办账号、认证、审核或发布。

如接入线上点餐：服务端必须托管微信 AppSecret、数据库和模型凭据；小程序只配置公开 API HTTPS 地址。域名备案、TLS 证书、微信合法请求域名和隐私政策/用户授权说明都需要按当时微信平台要求配置。真实支付须另行申请和接入微信支付，不得以演示按钮冒充支付成功。

## 常见问题

- **导入提示 AppID 无效**：将 `project.config.json` 中的游客 ID 替换为店主自己的 AppID，或按开发者工具测试模式操作。
- **线上请求失败**：检查 HTTPS 证书、备案、平台合法域名及后端访问日志；不要通过关闭校验作为正式解决方式。
- **生成的页面没有真实订单**：这是当前范围边界，需实现并部署独立订单服务后再接入。
