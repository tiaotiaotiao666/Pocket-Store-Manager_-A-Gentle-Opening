## 1. 交付范围

`miniprogram/` 从骨架改造为可对接 B1 后端的完整点餐参考工程：

- 领域层：`money / cart / orderStatus / scene / idempotency / orderView / errorText`。
- 服务层：`platform / request-core / request / session / auth / store / order / merchant`。
- 状态层：`visit-store`（到店上下文）、`cart-store`（按门店隔离购物车）。
- 组件层 13 个四件套：`store-header / category-nav / product-card / product-detail / fulfillment-switch / cart-bar / cart-panel / order-status / order-card / status-timeline / state-view / error-banner / loading-block`。
- 页面层 7 个：`home / menu / checkout / orders / order-detail / mine / merchant-orders`。

顾客路径：扫码 → 门店与履约 → 菜单加购 → 结算（幂等键）→ 创建订单 → 演示模拟支付 → 订单列表/详情 → 取消待付款。
店主路径：memberships 入口 → 10 秒轮询订单台 → 状态推进 → 商品上下架。

## 2. 关键约束（延续至今）

- 组件只收 properties、只发 triggerEvent，禁止 `wx.request`、固定路由、`globalData`、服务层 require。
- 页面不直接 `wx.request`；Token 只在 `services/session.js`，不写日志。
- 下单只传 `storeId / fulfillmentType / tableId / items / note`，金额由服务端计算。
- 同一 payload 复用 `Idempotency-Key`，payload 变化才换 Key。
- 模拟支付界面必须出现「演示模拟支付」，禁止「微信支付成功」。
- `templates/mini-program/` 未改动。
