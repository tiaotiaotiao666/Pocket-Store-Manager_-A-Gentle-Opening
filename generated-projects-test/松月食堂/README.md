# 松月食堂 微信小程序工程

这是由“智能开店”Windows 生成器导出的独立微信原生小程序工程。

## 导入预览

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选本文件所在目录。
3. 当前工程使用游客 AppID 作为预览配置。正式开发时，请在微信开发者工具中使用店主自己的小程序账号和 AppID。
4. 点击编译，检查首页、菜单、订单和我的页面。

## 门店配置

- 门店名称、地址、营业时间、公告、示例菜单和所选功能位于 `config/store.generated.json`。
- 商品价格以整数分保存，`priceText` 用于页面展示。
- 页面文件位于 `pages/`，全局样式位于 `app.wxss`。
- 页面订单目前是演示占位。修改商品配置不会创建真实订单或后端接口。

## 当前范围

这是可导入预览的前端模板，不含线上订单后端、登录、真实微信支付、外送或店主订单管理服务。请勿将演示数据当作真实营业数据。

正式发布需要店主使用自己的微信小程序账号与合法主体，配置 AppID、HTTPS 服务域名和业务后端，使用微信开发者工具上传代码，并自行提交平台审核。生成器不会代办注册、认证、审核或发布。

演示支付说明：此模板为演示工程。生成的模板当前不集成真实订单后端、真实微信支付或自动小程序发布。上线前需接入独立服务器、HTTPS 域名、合法域名配置、店铺业务数据及微信支付。
