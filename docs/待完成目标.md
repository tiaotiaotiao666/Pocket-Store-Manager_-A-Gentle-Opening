## 4. 当前已知工程风险

- 桌面 React 预览与导出 WXML 是两套实现，组合规格统一前不能保证一致。
- 本地导出脚本运行时引用 `src/domain/catalog.mjs`，但 electron-builder 包含列表未含 `src/`，安装包导出需优先验证。
- 当前静态模板无组件和服务层，不能与 B2 Base 候选混称。
- Agent Auth Guard 目前只校验 Bearer 形式，不是真实店主身份认证；B1 `SessionAuthGuard` 尚未接入 Agent。
- B1 的真实微信登录未用真实凭据验证，且尚未实现限流。
- 本地开发库保留了 B1 与 B2 冒烟产生的订单，正式演示前需按运维流程清理（`docs/B2小程序实现说明.md` 第 9 节）。
- Windows 安装包上次因 Electron 运行时下载超时失败，尚无最终安装验收证据。
- B2 的微信开发者工具编译、真机安全区与点击级视觉走查未执行；工具 CLI 服务端口当前处于关闭状态。
- B2 的「删除组件后仍可编译」未验证，只完成引用点隔离与静态校验。
- 真实小程序端到端、桌面点击级视觉走查和多分辨率验证仍需执行。

## 5. 永久红线

- 不以模拟支付冒充真实微信支付，不在生产开启 demo 登录/支付。
- 不做外送、公开店主注册或客户端授权。
- 不把任何密钥写入前端、小程序、导出工程、日志或仓库。
- 不让 Agent 直接生成/执行任意业务代码，不绕过注册表和 Composer。
- 不用文档、React 预览或功能 ID 代替真实实现与验收。
